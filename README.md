## 🦖 What I build

I ship **self-hosted tooling for on-chain work** — miners, pool contracts, mint automation, wallet ops. Everything runs on my own infra first, gets battle-tested, then lands here.

| Layer | What lives there |
|---|---|
| ⛏️ **Mining** | Stratum miners, relay plumbing, pool accounting contracts |
| 🔧 **PoW minting** | CUDA hashing pipelines, chain-state verification, broadcast |
| 🤖 **Automation** | Multi-wallet flows, eligibility checks, PnL analytics |
| 📜 **Contracts** | Solidity patterns, on-chain ledgers, test coverage |
